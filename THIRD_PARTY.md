# Dependencies and references

The project-specific renderer, scene geometry, procedural texture generation, math and UI code are in `src/` and `shaders/`. It does not contain downloaded model or texture assets. The small UI alphabet is defined directly in source as a bitmap pattern; no font files are bundled.

## Runtime/build dependencies

**GLFW 3.4** — window creation, OpenGL context, input and timing. CMake obtains the official source archive, or builds an explicitly supplied offline source directory. Retain GLFW's upstream license and copyright notices if redistributing that source.

- Official versioned getting-started guide: `https://www.glfw.org/docs/3.4/quick_guide.html`
- Official release: `https://github.com/glfw/glfw/releases/tag/3.4`
- Source archive used by CMake: `https://github.com/glfw/glfw/archive/refs/tags/3.4.zip`

**GLAD** — the generated `deps/glad/gl.h` loader already included in that GLFW source release. This header was generated by the GLAD project, not by the student team. Its implementation is enabled once in `src/glad_impl.c`. Keep all upstream notices when redistributing it.

- GLAD project: `https://github.com/Dav1dde/glad`
- GLAD C documentation: `https://github.com/Dav1dde/glad/wiki/C`
- Exact header source: `https://raw.githubusercontent.com/glfw/glfw/3.4/deps/glad/gl.h`

**CMake** — project configuration and dependency setup, not an engine or runtime renderer.

- FetchContent documentation: `https://cmake.org/cmake/help/latest/module/FetchContent.html`
- Visual Studio CMake documentation: `https://learn.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio?view=msvc-170`

The project uses a pinned, established GLFW release for reproducibility; it does not claim that 3.4 is the latest release. GLM, stb_image and GLUT are not used by this implementation.
